Common tasks

Import people from CSV

Open People, choose Import CSV, download the template if you need it, and upload a CSV file saved from Excel or Google Sheets.

Expected columns:

first_name, last_name, member_type, email, phone, address_line1, address_line2, city, state, zip_code

member_type must be Member or Non-member. state is a 2-letter code such as NJ.

Example with two records:

first_name,last_name,member_type,email,phone,address_line1,address_line2,city,state,zip_code
Ada,Member,Member,ada@example.org,555-0100,170 Greenbrook Rd.,,Green Brook,NJ,08812
Ben,Visitor,Non-member,ben@example.org,555-0101,12 Main St,Apt 2B,Plainfield,NJ,07060
Import contributions from CSV

Open Contributions, choose Import CSV, download the template if you need it, and upload a CSV file saved from Excel or Google Sheets. Contributors must already exist under People.

Expected columns:

date, first_name, last_name, email, fund, amount, method, fiscal_year, reference, note

method must be Check, Cash, Online, or Other. Dates use YYYY-MM-DD. Include email when two people share the same name. fiscal_year can be left blank if the date falls in an open year.

Example with two records:

date,first_name,last_name,email,fund,amount,method,fiscal_year,reference,note
2026-09-01,Ada,Member,ada@example.org,General Fund,40.00,Check,2026,1001,
2026-09-02,Ben,Visitor,ben@example.org,Missions Fund,15.50,Cash,2026,,Sunday gift
Record a contribution

Choose Contributions, then Record contribution. Select a contributor, open fiscal year, fund, and payment method.

Create acknowledgment letters

Open Reports and choose a person’s PDF link. Check the letter before distribution.

Close a fiscal year

An administrator can close the year under Administration. Review entries and totals first.
